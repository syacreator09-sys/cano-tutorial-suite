# Preparación para publicación futura

## Puede publicarse después de

- sustituir ejemplos y marcas privadas cuando corresponda;
- confirmar licencias de cada repositorio hermano;
- probar instalación limpia en macOS y Windows;
- comprobar que el auditor no detecte secretos, sesiones o outputs;
- publicar instrucciones genéricas para perfiles y credenciales;
- conservar la identidad Cano Digital fuera de la licencia de código.

## No incluir

- perfiles Cano reales;
- IDs de avatar o voz;
- sesiones Playwright;
- medios de entrenamiento;
- assets de clientes;
- rutas personales;
- tokens o llaves.

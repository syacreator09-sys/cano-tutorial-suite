# Clone checklist

After cloning the Suite:

```bash
npm install
npm run init
npm run verify
node bin/cano-tutorial.js doctor
node bin/cano-tutorial.js run examples/image-generator-short.request.json --mock
```

Confirm the sibling layout and initialize each skill separately.

Before live:

- Screen has Chromium, allow-list and an authorized demo session;
- HeyGen has private variables, profile and budget ceiling;
- VideoVox has a prepared `jobSlug`;
- Composer has FFmpeg and real assets;
- only required approvals are enabled;
- publication remains false;
- the first short and long pilots are reviewed manually.
